# Resolvix-AI Knowledge Base Data (`kb-data`)

This directory contains the verified, official knowledge base deliverables for **Resolvix-AI**, scraped and audited from the official AKGEC portal (`https://www.akgec.ac.in`) and AKTU portal (`https://erp.aktu.ac.in`).

## Deliverable Files

1. **`akgec_kb_100series.jsonl`**:
   - Primary import file formatted as one `KBEntry` per line.
   - All entries set to `status: "draft"` for Ops review and approval via the Ops Dashboard (`/v1/kb/import`).
   - 100-series IDs (`GEN-101+`, `ADM-101+`, `FEE-101+`, `EXM-101+`, `HST-101+`, `TRN-101+`, `EMG-101+`).
   - 0 prompt injection triggers, strictly adheres to `contracts/config/departments.yaml`.

2. **`VERIFY_WITH_A.md`**:
   - Comprehensive source provenance audit requested by Member C.
   - Detailed mapping of every entry ID to its official canonical URL and exact facts.
   - Complete documentation of the Top 40 missing items.

3. **`cag_kb.jsonl`**:
   - CAG reference knowledge base with `status: "approved"` for direct compilation by `resolvix_brain`.

4. **`cag_kb_export.json`**:
   - Full `KBExport` schema artifact containing version metadata and entry records.

5. **`cag_kb.csv`**:
   - Spreadsheet-friendly CSV export for administrative and faculty review.

6. **`cag_prompt_prefix.txt`**:
   - Deterministically compiled CAG prefix text generated by `resolvix_brain.kb.compiler`.
